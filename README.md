# Notes App

## Description
A note-taking app built with HTML, CSS, and JavaScript. It allows users to add, edit, and delete notes.

## Features
- Add, edit, and delete notes.
- Store notes locally in the browser (using LocalStorage).
- Simple, user-friendly interface.

## Technologies Used
- HTML, CSS and JavaScript
